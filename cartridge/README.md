An example cartridge executable. If you install the utilities in this repo using the command `pipx install git+https://github.com/DragonMinded/minidragon.git` you should be able to make a copy of this directory to get started writing your own cartridge. To compile this cartridge, once you've installed the utilities just type `make`. To run this cartridge, run the command `minidragon-emulator lib/bootrom.bin --cartridge helloworld.cart`.
